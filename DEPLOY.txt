ALIGN RAIL WEBSITE - PUTTING IT ONLINE (free, about 20 minutes)
===============================================================
Files: index.html (home page), demo.html (demo page), demo-map/ (the live demo map,
       served at alignrail.com.au/demo-map), images/, favicon.png

1. GitHub Desktop: File > New repository > "align-rail-website". Copy these files
   into it, commit to main, Publish repository.
2. render.com > New > Static Site > connect align-rail-website.
     Build command:      echo done
     Publish directory:  .
   Create Static Site. Render gives you an address like align-rail-website.onrender.com
3. Once you own alignrail.com.au: Render > your static site > Settings > Custom Domains >
   add alignrail.com.au and www.alignrail.com.au. Render shows the DNS records to add at
   your domain registrar. Render sets up https for you.

The enquiry form opens the visitor's email program with their details filled in,
addressed to admin@alignrail.com.au. When you want enquiries to arrive without that
step, a form service (for example Formspree) can be added later.

To change text: edit the designs on the canvas and ask Claude to re-export, or edit
index.html directly.

Visitor numbers: Cloudflare Web Analytics (Cloudflare dashboard > Web Analytics). The
line marked "Cloudflare Web Analytics" just before </body> in index.html, demo.html and
demo-map/index.html counts each visit; if a page is replaced or re-exported, put that
line back. It sets no cookies, so the site needs no cookie banner.

The demo map (demo-map/) is a stretch of a working coal terminal's rail loop. It needs
no server: everything loads from these files, and nothing a visitor changes is saved. To refresh it, replace the demo-map folder.
